# INAYOU — (주)이나유 corporate site

검색·AI 기반 B2B·B2C 벤처 스튜디오 (주)이나유의 회사 소개 사이트.
순수 정적 HTML (빌드 스텝 없음) · GitHub Pages 호스팅 · 커스텀 도메인 inayou.io.

## Services
- B2B: Dominus(dom-in-us.com), Presfi(presfi.io), Unimate(unimate.com)
- Featured: NeuPAI (SEO·AEO·GEO)
- B2C: 한술(Hansool), K-TravelMate(ktravelmate.com)

## Deploy
`main` 브랜치 루트를 GitHub Pages로 서빙. `CNAME` = inayou.io.
